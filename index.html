    Setup — step by step
    1. Open a new Google Sheet in your Google Drive.
    2. In row 1, add headers: Group, Gender, Event, Position, Chest No
    3. Add one row per Group/Gender/Event/Position (you can export the "Results" tab from this dashboard as Excel first and copy the column layout).
    4. Once the sports event starts, the judge only needs to fill in the Chest No column.
    5. File → Share → Publish to web → choose the correct sheet, format CSV, then Publish.
    6. Paste the link you get into the box above and click "Connect". The dashboard will then auto-refresh every 30 seconds.
